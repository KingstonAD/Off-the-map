# LuggageTag

A paper luggage tag with clipped corners, an eyelet and a short amber string, used for the streak counter and other small personal counters.

- `.otm-tag-wrap` > `button.otm-tag` > `small` (label) + `b` (value). `.amber` marks a new personal best.
- Put it on terminal surfaces only: the eyelet is punched in `--terminal-900`.
- Keep values to ≤ 8 characters ("12 days", "19 days").
